ENEL 585 · Lecture 10 · Study guide

Rectifiers: from the ac grid to a dc voltage

A diode has no gate. It turns on by itself when the circuit pushes current forward through it, and off when the circuit tries to push current backwards. The lecture starts by working out which diodes are on and how much average voltage you lose when source inductance slows the handover between them. Then it swaps the diodes for thyristors, whose firing angle α controls the output and can even reverse the power flow. It ends with power factor correction: shaping the grid current into a clean sine.

Part 1 · Diode basics

01What a rectifier does

A rectifier moves power from ac to dc. The grid is ac, but electronics, motor drives and dc transmission all need dc, so a rectifier is the front end of most electronic systems: it's the first thing power meets after leaving the plug.

The lecture's examples: HVDC transmission (ac grid into a dc line), power supplies for electronic devices, and motor drives and industrial converters. Throughout, the ac side is vg (single-phase) or vga, vgb, vgc (three-phase), and the dc side is vd.

Analogy · check valves in a pump

A hand pump pushes water back and forth, but check valves only let it through one way, so the tank on the far side only ever fills. Diodes are the check valves: the source sloshes back and forth (ac), and the diodes steer it so the dc side always sees the same polarity.

Tricky bits
  • Direction of power flow defines the converter. ac → dc is a rectifier, dc → ac is an inverter. An HVDC link has a rectifier at the sending end and an inverter at the receiving end.
  • A diode rectifier has no control input. Its output is set by the source and the circuit. Control (α) only arrives with thyristors in §15.

02The method of assumed states

You can't just "look" at a diode circuit and know which diodes conduct. So you guess, and then check the guess. Four steps:

  1. Assume a state for every diode, on or off, over one interval (for example, while vg > 0).
  2. Solve the circuit, treating on diodes as wires and off diodes as gaps. Find iD in each on diode and vD across each off diode.
  3. Check: an on diode needs iD ≥ 0. An off diode needs vD ≤ 0.
  4. If a check fails, flip that diode and solve again.
on:  iD ≥ 0      off:  vD ≤ 0 vD measured + at the anode

From here on the lecture plots everything against ωt, not t. One period is always 0 to 2π, whatever the frequency, so the results don't depend on 50 Hz versus 60 Hz.

Worked example: half-wave rectifier, resistive load

Source vg = V̂g sin ωt, diode D1 in series, resistor R carrying id with voltage vd.

IntervalAssumptionSolveCheck
Assumevg > 0D1 onid = vg/R > 0✓
vg < 0D1 offvD1 = vg < 0✓
Suppose insteadvg > 0D1 offvD1 = vg > 0✗
vg < 0D1 onid = vg/R < 0✗

So D1 conducts for 0 < ωt < π and blocks for π < ωt < 2π.

Try it: click D1 to assume on or off, then pick the interval
Analogy · Sudoku with pencil marks

You pencil in a guess, follow where it leads, and erase it the moment it contradicts something. The contradictions here are physical: a diode can't carry current backwards, and an off diode can't have its anode above its cathode.

Tricky bits
  • Check the other quantity. For an on diode you check its current (its voltage is 0 by assumption). For an off diode you check its voltage (its current is 0 by assumption). Checking vD = 0 on an on diode proves nothing.
  • Sign convention. vD is anode minus cathode. vD = vg < 0 means reverse biased, which is what an off diode should be.
  • Check every diode, not just the one you changed. A guess is only right when all checks pass at once.
  • vD = 0 or iD = 0 still passes (≥ and ≤). Those are the boundary instants where states switch.

03Half-wave rectifier: the average output

From §2: for 0 < ωt < π, D1 is on and vd = vg. For π < ωt < 2π, D1 is off, id = 0 and vd = 0. The output is the positive half of the sine, then nothing.

The dc value you care about is the average, ⟨vd⟩: total area under vd over one period, divided by the period 2π.

Worked example: deriving ⟨vd⟩ (θ = ωt)
⟨vd⟩ = 12π [ ∫0π V̂g sin θ dθ + ∫π2π 0 dθ ]         = V̂g2π [ −cos θ ]0π = V̂g2π ( 1 − (−1) )         = V̂gπ ≈ 0.318 V̂g
⟨vd⟩ = V̂g/π half-wave, no commutation inductance
Half-wave waveforms: change V̂g and R
Analogy · a pay cheque every other week

If you're paid $1000 every second week, your weekly average is $500, even though the weeks with no pay contributed nothing. The average divides by the whole period, including the empty half. That's why the 2π stays in the denominator.

Tricky bits
  • V̂g/π, not 2V̂g/π. 2V̂g/π ≈ 0.637 V̂g is the full-wave bridge (§8). Half-wave is half of that.
  • Peak, not rms. V̂g is the peak. A 120 V rms outlet has V̂g = 120√2 ≈ 170 V.
  • Peak reverse voltage. When off, vD1 = vg, so D1 must block V̂g at ωt = 3π/2.

Part 2 · Commutation

04Freewheeling diode and current commutation

Now the load draws a constant current Id (a model for a load with a big series inductor). A current source can never be opened, so Id always needs a path. A second diode, the freewheeling diode D2, sits across the output to give it one when D1 is off.

Worked example: assumed states

IntervalAssumptionSolveCheck
Assumevg > 0D1 oniD1 = Id > 0, vD2 = −vg < 0✓
vg < 0D2 oniD2 = Id > 0, vD1 = vg < 0✓
Suppose insteadvg > 0D2 onvD1 = vg > 0✗
vg < 0D1 onvD2 = −vg > 0✗

Result over one cycle:

  • 0 < ωt < π: D1 on, iD1 = Id, vd = vg
  • π < ωt < 2π: D2 on, iD2 = Id, vd = 0, vD1 = vg < 0
  • ωt > 2π: vg > 0 again, D1 on

Commutation means current passing from one device to another. Here it's instant: D1 → D2 at π, and back at 2π. Since vd has the same shape as in §3, ⟨vd⟩ = V̂g/π again.

Try it: toggle D1 and D2. Try both on, and both off.
Analogy · a heavy truck and a bypass lane

The load current is a loaded truck that can't stop. When the main road (D1 and the source) closes, the truck needs a bypass lane right there, or it crashes. D2 is that bypass: the current just loops through it and the load, and the source is left out.

Tricky bits
  • Both off is impossible with a current-source load: Id would have no path.
  • Both on is impossible without Lc: D2 forces vd = 0 while D1 forces vd = vg. That only works at the instant vg = 0, which is why commutation is instant here. With Lc (§5), both on becomes a real interval.
  • The current check always passes for whichever diode carries Id. The interesting check is the voltage on the off diode.

05Adding commutation inductance: four intervals

Real sources have stray inductance (or you add an inductor on purpose). Model it as Lc in series with vg, carrying the source current ig. The load is still a constant Id.

An inductor's current can't jump. Moving Id from D2 to D1 means ig has to ramp from 0 to Id, and that takes an angle u, the commutation angle. Each cycle now has four intervals:

IntervalAngleDiodesWhat happens
①0 to uD1, D2 onvd = 0, so Lc dig/dt = vg. ig rises until iD2 = 0.
②u to πD1 oniD2 = 0, D2 off, reverse biased by vd = vg > 0.
③π to π+uD1, D2 onvg < 0 across Lc: ig falls until iD1 = 0.
④π+u to 2πD2 oniD1 = 0, D1 off, reverse biased by vg < 0.

During both overlaps, KCL at the top node gives ig + iD2 = Id: whatever D1 picks up, D2 lets go of.

Analogy · a baton handover in a relay

Without Lc, the baton teleports from one runner to the other. With Lc, both runners hold the baton for a stretch of track while the grip moves from one hand to the other. During that stretch (① and ③), both diodes are on.

Tricky bits
  • vd = 0 during ① even though vg > 0. D2 is still on and shorts the output. All of vg is spent across Lc.
  • D1 starts conducting at 0, not at u. It turns on at 0 with zero current; u is when it has taken all of Id.
  • The overlap in ③ uses the same angle u as ①, because the same volt-second area is needed to ramp ig back down.

06Finding the commutation angle u

During ① the whole source voltage is across Lc, and ig goes from 0 to Id. Integrate that, and you get an area rule: the area under vg from 0 to u equals XcId, where Xc = ωLc.

Worked example: deriving u (half-wave)
① both on:   Lc digdt = V̂g sin ωt θ = ωt, dθ = ω dt:   ωLc dig = V̂g sin θ dθ ωLc ∫0Id dig = ∫0u V̂g sin θ dθ XcId = V̂g(1 − cos u) u = cos−1(1 − XcId/V̂g)

Lecture's numbers: x = XcId/V̂g = 0.134.

cos u = 1 − x = 1 − 0.134 = 0.866
u = cos−1(0.866) = 30.0° (0.524 rad)
XcId = V̂g(1 − cos u),   Xc = ωLc half-wave

More Id or more Lc means a bigger area to cover, so a longer overlap. The commutation lab in §5 shows this area shaded purple on vg: drag x and watch u follow.

Analogy · filling a bucket from a tap that opens slowly

The bucket's size is XcId. The tap is vg, which starts at zero and opens up like a sine. u is how long it takes to fill the bucket. A bigger bucket (more Id or Lc) takes longer; a stronger tap (bigger V̂g) fills it faster.

Tricky bits
  • Xc, not Lc. Xc = ωLc = 2πfLc, in ohms. Forgetting the 2π gives a much smaller u.
  • Calculator mode. cos−1 returns radians in many calculators. 0.524 rad is 30°.
  • u isn't proportional to x. Doubling x from 0.134 to 0.268 takes u from 30° to 42.9°, not 60°.
  • x = 1 gives u = 90°: the whole first quarter cycle is spent commutating.

07Effect of commutation on the average

During ① the output is held at 0 instead of following vg. So vd only follows vg from u to π, and the average shrinks. The missing slice of vg is exactly the area XcId from §6: the volt-seconds spent ramping ig up to Id.

Worked example: deriving ⟨vd⟩ with commutation
⟨vd⟩ = 12π ∫uπ V̂g sin θ dθ = V̂g2π(1 + cos u) with cos u = 1 − x,   x = XcId/V̂g: ⟨vd⟩ = V̂gπ(1 − x2)

Lecture's numbers: x = 0.134 (u = 30°).

⟨vd⟩/V̂g = (1/π)(1 − 0.134/2) = 0.3183 × 0.933 = 0.297
check: (1 + cos 30°)/(2π) = 1.866/6.283 = 0.297
without Lc: 1/π = 0.318, so commutation costs 0.021 V̂g
⟨vd⟩ = V̂gπ − XcId2π ideal value minus the lost area per period
Calculator: u and ⟨vd⟩ from circuit values
Analogy · a toll on every cycle

Every cycle, Lc charges a toll of XcId volt-radians to move the current over. The toll is the same no matter how big V̂g is; it only depends on how much current you move and how stiff the inductor is. Spread over 2π, it costs XcId/2π of average voltage.

Tricky bits
  • Only one notch counts. Interval ③ also has both diodes on, but there vd would be 0 anyway (D2 freewheels when vg < 0). Only ① removes positive area.
  • x/2, not x. ⟨vd⟩ = (V̂g/π)(1 − x/2). Writing (1 − x) double counts the loss.
  • No power is burned. The drop XcId/2π grows with Id like a resistor, but an ideal Lc dissipates nothing. It's a lossless voltage drop.

Part 3 · Single-phase bridge

08Single-phase full-wave bridge

Four diodes in two legs: D1 above D3 on the left, D2 above D4 on the right. vg sits between the legs, + toward the D1/D3 node. The dc rails feed the load Id. The bridge flips the source so the output is positive in both halves.

Worked example: assumed states

IntervalAssumptionSolveCheck
Assumevg > 0D1, D4 oniD1 = iD4 = Id, vD2 = vD3 = −vg < 0✓
vg < 0D2, D3 oniD2 = iD3 = Id, vD1 = vD4 = vg < 0✓
Suppose insteadvg > 0D2, D3 onvD1 = vD4 = vg > 0✗
vg < 0D1, D4 onvD2 = vD3 = −vg > 0✗
  • 0 < ωt < π: D1, D4 on, ig = Id, vd = vg
  • π < ωt < 2π: D2, D3 on, ig = −Id, vd = −vg

Commutation between the pairs is instant, at π and 2π. Compared with the half-wave, vd = |vg| repeats every π, so its ripple is at 2ω and its average doubles.

⟨vd⟩ = 2V̂g/π ≈ 0.637 V̂g bridge, no Lc
Try it: pick any combination of the four diodes
Bridge waveforms (no Lc)
Analogy · a reversing switch on a battery

Picture someone flipping the source around every half cycle so its + terminal always faces the top rail. D1, D4 connect it one way round; D2, D3 connect it the other way round. The diodes do the flipping automatically, exactly when vg changes sign.

Tricky bits
  • Pairs are diagonal. D1 goes with D4, and D2 with D3. D1 with D3 would freewheel through one leg (vd = 0) and fails the check because vD4 = vg > 0.
  • ig is ac. The source current is a ±Id square wave, not dc. Its average is 0 and its rms is Id.
  • Ripple at 2ω: 120 Hz on a 60 Hz grid, 100 Hz on a 50 Hz grid.

09The bridge with commutation inductance

Put Lc in series with vg, same constant Id. Handing the current between the pairs is no longer instant: it takes an angle u. And this time the source current doesn't go from 0 to Id; it reverses, from −Id to +Id.

IntervalAngleDiodesWhat happens
①0 to uall four onvd = 0. Lc dig/dt = vg: ig rises from −Id to Id.
②u to πD1, D4iD2 = iD3 = 0: D2, D3 off. vd = vg.
③π to π+uall four onvd = 0. vg < 0: ig falls to −Id.
④π+u to 2πD2, D3iD1 = iD4 = 0: D1, D4 off. vd = −vg.

While all four are on, KCL splits the current: iD1 = iD4 = (Id + ig)/2 and iD2 = iD3 = (Id − ig)/2. (The slide plots iD1; this split is what that plot shows.)

Analogy · a U-turn instead of a lane change

In the half-wave, the current only changed lanes (0 to Id in the source). In the bridge the source current makes a full U-turn, from −Id to +Id. A U-turn covers twice the distance, so with the same Lc it takes longer.

Tricky bits
  • vd = 0 in both ① and ③, and this time both notches cost you, because without Lc the output would be |vg| > 0 in both places.
  • All four on doesn't short the source here: Lc takes vg. Without Lc, all four on would short vg, which is why it can't happen in §8.
  • ig swings by 2Id, which is where the 2 in the next section comes from.

10Finding u for the bridge

Same idea as §6, but ig goes from −Id to Id, so the volt-second area needed is twice as big.

Worked example: deriving u (bridge)
① all four on:   Lc digdt = V̂g sin ωt θ = ωt:   ωLc dig = V̂g sin θ dθ ωLc ∫−IdId dig = ∫0u V̂g sin θ dθ 2XcId = V̂g(1 − cos u) u = cos−1(1 − 2XcId/V̂g)

Lecture's numbers: x = XcId/V̂g = 0.067. Dividing by V̂g, the result is cos u = 1 − 2x.

2x = 2 × 0.067 = 0.134
cos u = 1 − 2x = 1 − 0.134 = 0.866
u = cos−1(0.866) = 30.0°

Half the XcId of the half-wave example, same u. The commutation lab in §9 starts at this value.

2XcId = V̂g(1 − cos u),   cos u = 1 − 2x,   x = XcId/V̂g bridge
Analogy · the same bucket, twice as big

Same slowly opening tap (vg), but now the bucket holds 2XcId because the current must be drained from −Id to zero and filled to +Id. It takes longer to fill.

Tricky bits
  • Same x, different formula. The updated slides use x = XcId/V̂g everywhere, for the half-wave and the bridge. The bridge's formula then has 2x in it: cos u = 1 − 2x. Plug in x, not 2x.
  • Same parts, longer overlap. Moving the half-wave example (XcId/V̂g = 0.134) into a bridge gives cos u = 1 − 0.268, u = 42.9°, not 30°.
  • Forgetting the 2 with 0.067 gives u = 21.1°, a classic wrong answer.

11Average output of the bridge

vd now has two notches per period, at 0 to u and π to π+u, and each one removes an area of 2XcId. Since the waveform repeats every π, average over π.

The slide also notes: in steady state, ⟨vLd⟩ = 0, so ⟨v⟩ = ⟨vd⟩. A real "constant current" load is a big inductor Ld in front of the actual load. An inductor's average voltage is zero in steady state, so whatever sits behind Ld receives exactly ⟨vd⟩.

Worked example: deriving ⟨vd⟩ (bridge)
⟨vd⟩ = 1π ∫uπ V̂g sin θ dθ = V̂gπ(1 + cos u) with cos u = 1 − 2x,   x = XcId/V̂g: ⟨vd⟩ = 2V̂gπ(1 − x)

Lecture's numbers: x = XcId/V̂g = 0.067, so u = 30°.

⟨vd⟩/V̂g = (2/π)(1 − 0.067) = 0.6366 × 0.933 = 0.594
check: (1 + cos 30°)/π = 1.866/3.1416 = 0.594
without Lc: 2/π = 0.637, so commutation costs 0.043 V̂g
⟨vd⟩ = 2V̂gπ − 2XcIdπ vd loses 2XcId every half cycle
Calculator: u and ⟨vd⟩ from circuit values
Analogy · double toll, twice as often

The half-wave paid a toll of XcId once per 2π. The bridge pays 2XcId (bigger swing) every π (two notches). That's four times the average loss: 2XcId/π versus XcId/2π.

Tricky bits
  • Divide by π, not 2π. The bridge output repeats every π, so (V̂g/π)(1 + cos u), not (V̂g/2π)(1 + cos u).
  • (1 − x), not (1 − x/2). The half-wave has (1 − x/2); the bridge has (1 − x), because it loses twice as much area each notch. With x = 0.067, using (1 − x/2) gives 0.615, which is wrong.
  • 4× the half-wave loss for the same source, Lc and Id.

Part 4 · Three-phase diode bridge

12The three-phase diode bridge

Three legs, one per phase. In the lecture's numbering, D1, D2, D3 are the top diodes of phases a, b, c, and D4, D5, D6 are the bottom diodes of a, b, c. Each phase voltage is measured from the neutral N.

The assumption that works: the top diode of the highest phase and the bottom diode of the lowest phase are on. The top rail then sits at the highest phase voltage and the bottom rail at the lowest.

The slides write line-to-line voltages as two letters: vab = vga − vgb, vba = vgb − vga = −vab, and so on.

Worked example: vga highest, vgb lowest

AssumptionSolveCheck
AssumeD1, D5 oniD1 = iD5 = Id; vD2 = vba < 0, vD3 = vca < 0✓
vD4 = vba < 0, vD6 = vbc < 0✓
Suppose insteadD3, D5 onvD1 = vac > 0✗

Only the assumed pair passes. In this interval vd = vab.

vd = vmax − vmin the largest line-to-line voltage at each instant

With vga = V̂g sin ωt, vgb 120° behind and vgc 120° ahead, the highest phase changes every 120° and so does the lowest, offset by 60°. So the conducting pair changes every 60°: six pulses per cycle, peak √3V̂g, and vd ripples at 6ω. Without Lc, each commutation is instant, every π/3. vd stays between 1.5V̂g (where two phases cross) and √3V̂g ≈ 1.732V̂g (the line-to-line peak).

Three-phase explorer: drag ωt, or click diodes to make your own assumption
Analogy · the tallest and the shortest in a group photo

Three people keep standing up and crouching down in turn. The top rail always holds hands with whoever is tallest right now, and the bottom rail with whoever is shortest. vd is the height difference between those two, which never drops very low, because someone is always fairly tall and someone fairly short.

Tricky bits
  • Numbering. This lecture uses D1 to D3 on top (a, b, c) and D4 to D6 on the bottom (a, b, c). Some textbooks number in conduction order instead (odd on top). Use the lecture's numbering on the exam.
  • vd is line-to-line, so its peak is √3V̂g, not V̂g. With V̂g = 170 V, vd swings between 255 V and 294 V.
  • Off-diode voltages are differences of phase voltages: top diode k sees vgk − vmax, bottom diode k sees vmin − vgk. Both are ≤ 0 only for the max/min choice.
  • Two top diodes on at once would short two phases together through the top rail.

13The three-phase bridge with commutation inductance

Now put an Lc in each line, between each source and its leg. The load is still a constant Id. Each of the six commutations per cycle now takes an angle u instead of happening instantly.

The difference from the single-phase bridge: only one row commutates at a time. When phase a overtakes phase c at ωt = π/6, the top-row current moves from D3 to D1 while the bottom row (D5) just keeps conducting. At π/2, phase c drops below phase b and the bottom row hands over from D5 to D6.

IntervalAngleDiodesvd
①π/6 to π/6+uD1, D3 both on (vga > vgc), plus D5½(vcb + vab)
②π/6+u to π/2igc = 0: D3 off; D1, D5 onvab
③π/2 to π/2+uD5, D6 both on (vgc < vgb), plus D1½(vab + vac)
④π/2+u to 5π/6igb = 0: D5 off; D1, D6 onvac

During an overlap, vd doesn't drop to zero as it did in the single-phase bridge. It sits halfway between the two line voltages involved, because the top rail is tied to two phases at once through two equal inductors.

Worked example: vd and u during overlap ① (D3 → D1)

Only three branches carry current: phase a through Lc and D1, phase c through Lc and D3 (both to the top rail), and phase b through Lc and D5 (the bottom rail).

Analogy · two taps feeding one hose

The top rail is a hose fed by two taps (phases a and c) through identical narrow pipes (the Lc's). While both taps are open, the pressure in the hose settles halfway between the two tap pressures. That's why vd sits at the average of the two line voltages during overlap, rather than at zero.

Tricky bits
  • Two inductors, one line-to-line voltage. The commutating voltage is vac (peak √3V̂g), and it drives the current through two Lc's in series. That's where 2XcId and √3V̂g both come from.
  • iga + igc = Id during ①, because both feed the top rail. Unlike the single-phase bridge, each line current only goes from 0 to Id, not from −Id to Id.
  • vd is not zero during overlap. It's ½(vcb + vab), the average of the outgoing and incoming line voltages.
  • θ starts at the crossing. θ = ωt − π/6, measured from where vga = vgc, not from ωt = 0.

14Average output of the three-phase bridge

Without Lc, vd is made of six identical 60° slices of line voltage. Measure θ from a pulse's peak and each slice is √3V̂g cos θ for −π/6 < θ < π/6. Average one slice and you have the whole average.

Worked example: ⟨vd⟩ with and without overlap

Tricky bits

  • 3/π, not 6/π. Six notches of XcId over 2π give 6XcId/(2π) = 3XcId/π.
  • Same XcId, compare the drops: half-wave XcId/2π (0.159), single-phase bridge 2XcId/π (0.637), three-phase 3XcId/π (0.955).

Part 5 · Phase-controlled rectifiers

15Half-wave phase-controlled rectifier

Swap D1 for a thyristor S1. A thyristor is a diode with a gate: it turns on only when it's forward biased (vS1 > 0) and it receives a gate pulse iG. It turns off by itself when its current reaches zero. Firing it at ωt = α instead of 0 chops off the start of each positive half cycle.

Analogy · a door that needs a doorbell

A diode is a swinging door that opens the moment someone pushes on it. A thyristor is a door that stays shut until you ring the bell, even with someone pushing. Once open, it stays open until nobody is walking through. α is how long you wait before ringing.

Tricky bits
  • Gate starts it, current stops it. You can't turn a thyristor off with the gate. It only turns off when its current reaches zero (here at ωt = π, where vg and so id reach zero).
  • Still divide by 2π. Same as the diode half-wave: the average covers the whole period.
  • α is measured from where the diode would have turned on (ωt = 0 here), not from the gate signal's own timing.

16The thyristor bridge

Replace all four bridge diodes with thyristors S1 to S4 (same positions as D1 to D4) and keep the constant-current load Id. Fire S1, S4 at α and S2, S3 at π + α.

Worked example: assumed states

  • π + α to 2π + α: S2, S3 on, ig = −Id, vd = −vg
  • After 2π + α: S1, S4 fired again

Commutation is instant (no Lc yet), and it happens when the next pair is fired. Compared with diodes, ig is delayed by α.

Analogy · holding the door after the crowd turns around

With a diode bridge, the moment vg flips, the other pair grabs the current. With thyristors, the other pair has to wait for its gate pulse, so the first pair keeps hold of Id even while vg is pushing the wrong way. During that stretch the output is negative.

Tricky bits
  • cos α, not (1 + cos α). The half-wave with R (§15) uses (1 + cos α)/2π because the current stops at π. With constant Id the bridge keeps conducting past π, so the negative slice counts and you get (2/π) cos α.
  • vd can be negative, id can't. Thyristors only conduct one way, so Id > 0 always. Only the voltage changes sign.
  • α = 90° gives zero average, even though vd is never zero for long: the positive and negative slices cancel.

17Reversing the power flow: rectifier or inverter

Put a real dc side on the bridge: a smoothing inductor Ld and a dc voltage source vo. In steady state ⟨vLd⟩ = 0, so the bridge's average voltage must equal vo:

Operating point: drag α, or enter vo to find the α it needs
Analogy · a one-way street with a hill

Traffic (Id) can only drive one way. Whether the cars are going downhill (giving energy to the dc side) or uphill (taking energy from it, which goes back to the grid) depends on the slope, which is the sign of vd. α tilts the hill.

Tricky bits
  • Inverting needs a dc source. A resistor or a passive load can't make vo negative. Something on the dc side (a battery, another converter, an HVDC line) has to push energy back.
  • Sign of P = sign of vo, because Id is always positive.
  • To find α from a given vo: cos α = vo/(2V̂g/π). A negative vo gives α > 90°.

18What the grid sees

From the grid's side, ig is still a ±Id square wave, but now delayed by α. Its fundamental (the 60 Hz part) is a sine of peak (4/π)Id that lags vg by α.

Îg1 = 4πId, lagging vg by α P = ½V̂gÎg1 cos α = 2V̂gπId cos α = ⟨vd⟩Id Q = ½V̂gÎg1 sin α > 0 for 0 < α < π absorbed rms: Ig = Id,   Ig1 = Îg1/√2 = 2√2πId kp = PS = Ig1Ig cos α ≈ 0.9 cos α

The ac-side power from the fundamental matches the dc-side power ⟨vd⟩Id exactly. The harmonics carry no average power; they only add to the rms current.

Grid current: drag α to delay the square wave
Analogy · pushing a swing late

Push a swing exactly as it moves away from you and all your effort goes into it (α = 0). Push late and part of each push fights the swing's motion. You're still working just as hard (same rms current), but less of it does useful work. The wasted part is the reactive power Q.

Tricky bits
  • Two separate reasons kp < 1. The 0.9 comes from the square wave's harmonics (Ig1/Ig). The cos α comes from the delay. Even at α = 0 a diode bridge only reaches 0.9.
  • Q is always absorbed (positive) for 0 < α < π, in both rectifier and inverter mode, because the current always lags.
  • Peak versus rms. Îg1 = 4Id/π = 1.27Id is a peak; Ig1 = 0.90Id is its rms.

20How late can you fire? Commutation failure

The overlap needs vg to push the right way for its whole duration. After π, vg reverses and starts pulling the current back. So the overlap must end before π:

α + u < π,   extinction angle γ = π − (α + u) limit γ = 0:   cos α − 2x = −1  ⇒  αmax = cos−1(2x − 1) ⟨vd⟩ ≥ −2V̂gπ(1 − x) most negative possible output

In practice γ is kept above zero to cover the thyristors' turn-off time: the outgoing pair needs a little reverse voltage after its current reaches zero before it can block again.

Worked example: the slide's two firing angles

  • α1 = 140° < αmax: the area under vg before π reaches 2XcId, so commutation completes.
  • α2 = 165° > αmax: the area left before π is less than 2XcId. ig turns back before reaching −Id, so S1, S4 stay on and vd = vg swings positive. Fired again at 3π + α2, it fails the same way.

The slide doesn't give x for this example. Any x between 0.017 and 0.117 puts αmax between 140° and 165°.

After a failure

With a real dc side (finite Ld, vo < 0 while inverting), Ld did/dt = vd − vo. Normally ⟨vd⟩ = vo and id only ripples. After a failure, vd = vg and Ld did/dt = vg + |vo|, so id climbs by 2π|vo|/(ωLd) net per cycle. In practice you fire earlier to commutate again, and the dc source lowers |vo| to stop the rise.

Causes of commutation failure: late firing, a dip in V̂g, or a rise in Id. All three make the available area smaller than 2XcId, or the needed area bigger.

Firing limit calculator
Analogy · a tag-team handover before the bell

The incoming wrestler has to fully take over before the round bell rings at π. If they jump in too late, the bell rings mid-handover, the old wrestler is still holding on, and now the match goes the wrong way: the dc source starts dumping current into a short.

Tricky bits
  • Inverting operation is where failure happens. You only fire near 180° when inverting, which is exactly when you're closest to the limit.
  • αmax < 180° whenever x > 0. With x = 0.14, αmax = cos−1(−0.72) = 136.1°.
  • γ = π − α − u, all in the same units. It's the margin after the overlap, not the overlap itself.
  • The lasting problem after a failure is id climbing, cycle after cycle, until the firing or vo is corrected.

21The three-phase thyristor bridge

Thyristors S1 to S6 in the same places as D1 to D6. Here α counts from where the diode would have turned on: the natural commutation point, for example ωt = π/6 for S1, where vga overtakes vgc. Each output piece is still a 60° slice of a line voltage, just taken α later.

⟨vd⟩ = 3√3V̂gπ cos α − 3XcIdπ the second term only with Lc

As before, it inverts past α = π/2 and needs α + u < π. In HVDC, each end uses two of these bridges in series (a 12-pulse converter).

Lecture's numbers: α = 30° (no Lc): ⟨vd⟩/V̂g = 1.654 × cos 30° = 1.654 × 0.866 = 1.43.

Three-phase thyristor bridge: drag α
Analogy · the group photo, but you wait before switching

In the diode bridge (§12) the rail switches to the new tallest person the instant they become tallest. With thyristors you wait α before switching, so for a while the rail is still holding hands with someone who is no longer the tallest. The longer you wait, the lower the average height difference.

Tricky bits
  • α = 0 is not ωt = 0. It's the crossing point of two phases (π/6 for phase a), where a diode would naturally take over.
  • 3XcId/π is the same drop as the three-phase diode bridge (§14), at any α.
  • Single-phase: (2V̂g/π) cos α. Three-phase: (3√3V̂g/π) cos α. Same cos α shape, bigger amplitude.

Part 6 · Power factor correction

22Why power factor correction?

The diode bridge with a constant-current load draws a square wave ig = ±Id, in phase with vg. That square wave is mostly fundamental, plus a lot of harmonics.

rms: Ig = Id,   Ig1 = 2√2πId = 0.90Id kp = PS = VgIg1VgIg = 0.90 THD = √(Ig2 − Ig12)Ig1 = √(1 − 0.902)0.90 = 48% square-wave harmonics: Igh = Ig1/h, odd h 33% at the 3rd, 20% at the 5th

Worked example: a 2 kW diode bridge on 230 V

Europe limits each device's harmonics (IEC 61000-3-2, up to 16 A per phase): 2.30 A at the 3rd and 1.14 A at the 5th.

Ig1 = P/Vg = 2000/230 = 8.7 A (current in phase, so P = VgIg1)
Ig3 = 8.7/3 = 2.9 A > 2.30 A fails
Ig5 = 8.7/5 = 1.7 A > 1.14 A fails

The goal of PFC: make ig a sine in phase with vg, so THD = 0 and kp = 1.

Harmonic check: does a diode bridge pass the limit?
Analogy · carrying groceries in a lumpy bag

Only the fundamental delivers average power, like the groceries themselves. The harmonics are the extra weight of a badly shaped bag: they don't get anything home, but your arms (the wires and the grid) still have to carry them. PFC is a better bag.

Tricky bits
  • In phase isn't enough. The diode bridge's current is perfectly in phase (no delay), yet kp = 0.90. The shortfall is all distortion.
  • THD divides by Ig1, not Ig. √(1 − 0.81)/0.90 = 0.436/0.90 = 48%.
  • Igh = Ig1/h uses the fundamental's rms, not Id.
  • The limits are in amps, not percent, so a bigger device fails sooner. The same bridge at lower power can pass.

23The boost PFC rectifier

Which load draws a sinusoidal current? A resistor: ig = vg/R, in phase, kp = 1, THD = 0. The problem is that then vd = |vg| swings from 0 to V̂g twice per cycle, and a dc load needs a steady voltage.

The fix is to put a boost converter between the bridge and the load. C holds the output steady at Vd, and L sits in series with the bridge, so its current can be shaped. Seen from the boost, the bridge is just a source |vg|.

The boost as a resistor

  • Goal: the grid sees a resistor, ig = vg/Re. After the bridge that means iL = |vg|/Re, the same shape as |vg|.
  • Q1 on: vL = |vg|, so iL rises. Q1 off: vL = |vg| − Vd < 0, so iL falls.
  • So a controller can switch Q1 to hold iL on that shape, provided Vd > V̂g.
  • Re is not a component and not the load R: it's the ratio vg/ig the control enforces. The power P = V̂g2/(2Re) goes to the load.

The duty ratio must follow the line

|vg| barely changes within one switching cycle (60 Hz against tens of kHz), so each cycle is nearly a steady state:

⟨vL⟩Ts = d|vg| + (1 − d)(|vg| − Vd) ≈ 0 d(t) ≈ 1 − |vg(t)|/Vd the Topic 3 boost relation, at each instant

d = 1 at the zero crossings and lowest at the line peak. d ≥ 0 there needs Vd > V̂g.

lecture example: V̂g = 170 V, Vd = 400 V
d at the peak = 1 − 170/400 = 0.575 ≈ 0.58; d at the zero crossings = 1

The waveforms

ig follows vg apart from a small switching ripple: kp ≈ 1 and very low THD. The input power p = vgig = P(1 − cos 2ωt) pulses at 2ω while the load takes a steady P, so C absorbs the difference and vd ripples at 2ω (Topic 8).

Boost PFC: the duty ratio over a line cycle
Analogy · a cruise control that follows a hilly road

The controller wants the current to trace a perfect sine, but the "road" |vg| keeps changing height. Near the zero crossings there's almost no push from the source, so the switch stays on nearly all the time (d ≈ 1). At the peak the source pushes hard, so it only needs a short on-time (d ≈ 0.58).

Tricky bits
  • Vd must exceed V̂g, not the rms. A 120 V rms line has V̂g ≈ 170 V, which is why PFC outputs sit around 400 V.
  • d is highest at the zero crossing (d = 1) and lowest at the peak. It's easy to get this backwards.
  • Re is a control target, not a part you can point to. Bigger Re means less current and less power.
  • The output ripple is at 2ω (120 Hz), not the switching frequency. It comes from the pulsing input power, and C has to be sized for it.

24Totem-pole PFC and back to the H-bridge

The boost PFC has three devices in the current path at any time: two bridge diodes, then Q1 or D5. The totem-pole removes the bridge and has only two, so less conduction loss.

  • Fast leg Q1, Q2: switches at the switching frequency.
  • Slow leg D1, D2: changes over once per line half-cycle.

It works as a boost in each half-cycle, and the other switch acts as the synchronous rectifier:

Totem pole: step through the four states

Back to the single-phase inverter

Replace D1, D2 with MOSFETs Q3, Q4 and you have the H-bridge of Topic 7, with the grid on its ac side: the active rectifier.

  • Cost: under Topic 7's PWM, all four switch at the switching frequency, so more switching loss.
  • Gain: no diode fixes the sign of ig, so P flows either way, ac to dc or dc to ac.
  • Gain: ig can lead or lag vg, so it can supply or absorb Q to support the grid.
  • Unipolar PWM: ripple at twice the switching frequency, so a smaller L.
