Standing waves and interference

Every topic in this lecture is the same move: add two waves together and see what survives. At a boundary, the incident power splits into a reflected and a transmitted part. On a string or in a pipe, two waves running opposite ways add into a standing wave, and the ends decide which wavelengths fit. Two sound waves running the same way add into a louder or quieter wave depending on how far out of step they are.

Part 1 · Energy at a boundary

01Where the power goes at a boundary

When a wave hits the boundary between two media (say, a light string tied to a heavy one), part of it bounces back and part of it goes through. Energy can't appear or disappear at the join, so the power that arrives must equal the power that leaves:

Pf = Pi  ⟹  Pr + Pt = Pi reflected + transmitted = incident PrPi + PtPi = 1

Each medium has an impedance Z (how hard it is to shake). The amplitude coefficients r and t tell you how big the reflected and transmitted waves are compared to the incident one. The power fractions are called R (reflectance) and T (transmittance):

r = Z2 − Z1Z1 + Z2,    t = 2Z1Z1 + Z2 amplitude ratios (lecture's notation) R = PrPi = r2,    T = PtPi = Z2Z1t2 = 4Z1Z2(Z1 + Z2)2 T + R = 1    but    r + t ≠ 1 in general

Why does T carry the extra factor Z2Z1? Because a wave's power depends on its amplitude squared and on the impedance of the medium it is travelling in. The reflected wave stays in medium 1, so no correction. The transmitted wave lives in medium 2, so its power gets rescaled by Z2Z1.

Lecture derivation: proving T + R = 1 (pages 1 and 2)
1. Conservation of energy: Pr + Pt = Pi  ⟹  PrPi + PtPi = 1
2. Write in terms of r and t: PrPi + PtPi = r2 + Z2Z1t2
3. Substitute r and t: = (Z2 − Z1Z1 + Z2)2 + Z2Z1(2Z1Z1 + Z2)2
4. Square, cancel one Z1: = (Z2 − Z1)2(Z1 + Z2)2 + 4Z1Z2(Z1 + Z2)2
5. Expand the top: = Z12 + Z22 − 2Z1Z2 + 4Z1Z2(Z1 + Z2)2 = Z12 + Z22 + 2Z1Z2(Z1 + Z2)2
6. The top is (Z1 + Z2)2: = 1  ⟹  T + R = 1 ✓
Practice example (my numbers, not from the lecture): Z1 = 1.0, Z2 = 4.0
r = 4.0 − 1.01.0 + 4.0 = 35 = 0.60    t = 2(1.0)5.0 = 0.40
R = r2 = 0.36    T = 4.01.0(0.40)2 = 4 × 0.16 = 0.64
check: R + T = 0.36 + 0.64 = 1.00 ✓   (36% of the power bounces back, 64% goes through)

Analogy · a ball hitting another ball

Roll a ball into a second ball of the same mass and it stops dead while the other one takes all the energy (Z1 = Z2: R = 0, T = 1). Roll it into a bowling ball and it mostly bounces back (Z2 ≫ Z1: R → 1). Roll a bowling ball into a ping-pong ball and the little ball flies off fast (big amplitude), yet it carries only a slice of the energy. Matching is what lets energy cross.

Tricky bits
  • Powers add to 1, amplitudes don't. On an exam, "fraction of energy transmitted" means T, not t. Always square, and for T also multiply by Z2Z1.
  • t can be bigger than 1. Going from high to low impedance (Z1 = 3, Z2 = 1) gives t = 1.5. That's fine: the factor Z2Z1 = 13 brings T down to 0.75, so energy is still conserved.
  • Sign of r. If you add the lecture's r and t exactly as written, you get Z2 − Z1 + 2Z1Z1 + Z2 = 1, which seems to contradict the note "r + t ≠ 1". The usual displacement convention on a string is r = Z1 − Z2Z1 + Z2, which gives 1 + r = t and r + t ≠ 1. The sign of r only tells you whether the reflection flips upside down. It never affects energy, since R = r2. Check which sign your instructor wants on exams.

Part 2 · Standing waves on a string

02Two travelling waves make one standing wave

Send two identical waves along a string in opposite directions. They pass through each other and interfere. Wave 1 moves right, wave 2 moves left:

y1 = ym sin(kx − ωt)    y2 = ym sin(kx + ωt)    yR = y1 + y2 sin α + sin β = 2 sin(α + β2) cos(α − β2) yR = [2ym sin(kx)] cos(ωt)

Read the result in two pieces. 2ym sin(kx) depends only on position: it's the standing wave's amplitude at each point, so at any frozen moment the string is a sine curve. cos(ωt) depends only on time: the whole shape just scales up and down in place. Nothing moves along the string.

  • Nodes (never move): sin(kx) = 0, so x = 0, λ2, λ, 3λ2, …
  • Antinodes (biggest swing, amplitude 2ym): sin(kx) = ±1, so x = λ4, 3λ4, 5λ4, …
Lecture derivation: adding y1 and y2 (pages 3 and 4)
1. Let α = kx − ωt,   β = kx + ωt
2. Half sum: α + β2 = 2kx2 = kx
3. Half difference: α − β2 = −2ωt2 = −ωt
4. Apply the identity: yR = ym(sin α + sin β) = 2ym sin(kx) cos(−ωt)
5. Cosine is even, cos(−ωt) = cos(ωt): yR = 2ym sin(kx) cos(ωt)
6. Not of the form sin(kx − ωt) ⟹ not a travelling wave ✓
Try it: watch two travelling waves build a standing wave
y1 (moving right)y2 (moving left)yR = y1 + y2
Analogy · a skipping rope

Two kids swinging a skipping rope make one big hump that goes up and down. The hump doesn't travel toward either kid; it just breathes in place. The ends (the kids' hands) barely move: those are nodes. The middle swings the most: that's the antinode.

Tricky bits
  • Typo in the boxed identity (page 3). The notes write cos(α + β2). It should be cos(α − β2). With the typo you'd get cos(kx), and the time dependence would vanish entirely.
  • The amplitude is 2ym|sin(kx)|, not 2ym. 2ym is only the amplitude at the antinodes. At a point where sin(kx) = 0.5, each bit of string swings only ym.
  • Node spacing is λ2, not λ. Adjacent nodes are πk apart. A node and its neighbouring antinode are λ4 apart.
  • "Not a travelling wave" test. Look for x and t locked together as (kx ± ωt). In a standing wave they sit in separate factors.

03Harmonics on a stretched string

A string clamped at both ends must have a node at each end. So only standing waves that fit a whole number of half-wavelengths into the length L are allowed. Each allowed pattern is a harmonic (or normal mode).

HarmonicFitNodes NAntinodes A
1st (fundamental)L = λ221
2ndL = λ32
3rdL = 3λ243
nthL = nλ2n + 1n

Solve L = nλ2 for λ, then use f = vλ:

λ = 2Ln,   n = 1, 2, 3, … allowed wavelengths f = vλ = nv2L resonant frequencies f1 = v2L fundamental mode, n = 1

Every harmonic is a whole-number multiple of the fundamental: fn = n f1. So the gap between neighbouring resonances is always f1.

Practice example (my numbers): L = 0.80 m, v = 240 m/s
fundamental: f1 = v2L = 2402(0.80) = 2401.6 = 150 Hz
3rd harmonic wavelength: λ3 = 2L3 = 1.63 = 0.533 m
3rd harmonic frequency: f3 = 3 × 150 = 450 Hz   (check: vλ3 = 2400.533 = 450 Hz ✓)

Analogy · fitting tiles in a hallway

You're tiling a hallway of length L, and you may only use half-wavelength tiles that are all the same size. One big tile, two medium tiles, three smaller tiles: each is a harmonic. A size that leaves a gap at the end isn't allowed, because the ends must be nodes.

Tricky bits
  • Wavelength shrinks, frequency grows. Higher n means shorter λ = 2Ln but higher f = nv2L. The wave speed v is the same for every harmonic, because it's set by the string, not by n.
  • Count nodes carefully. The two clamped ends are nodes too. The nth harmonic has n + 1 nodes and n antinodes.
  • Two neighbouring resonances give you f1. If a string resonates at 300 Hz and next at 375 Hz, f1 = 75 Hz (and 300 Hz is n = 4).

Part 3 · Standing sound waves in pipes

04Sound in a pipe: displacement vs pressure

Sound in a pipe is also a standing wave, but the air molecules move along the pipe (longitudinal oscillation), not up and down. The lecture sorts pipes into three cases:

Case 1 · Both ends closed§5
Case 2 · One end open§6
Case 3 · Both ends open§7

The curves in pipe diagrams are not pictures of the air going up and down. They are graphs of how far molecules move (displacement) or how much the pressure changes, plotted against position x. And each standing sound wave can be described two ways:

  • Displacement: how far each molecule swings back and forth. A closed end is a wall, so molecules there can't move: displacement node. An open end lets air slosh freely: displacement antinode.
  • Pressure: how much the air is squeezed or stretched. At a wall, molecules pile up against it or get pulled away from it, so the pressure swings the most: pressure antinode. At an open end the air is held at room pressure: pressure node.
pressure node ⟺ displacement antinode displacement node ⟺ pressure antinode

For a pipe closed at both ends (1st harmonic): displacement is zero at both ends and maximum in the middle. Pressure is maximum at both ends and zero in the middle.

Try it: air molecules in a pipe
Dots are air molecules. Switch the curve between displacement and pressure and watch the nodes swap places.
Analogy · a crowd in a hallway

People pushed against a wall can't move forward (displacement node), but they get squashed together the most (pressure antinode). People in the open middle of the crowd can step back and forth a lot (displacement antinode), and they never get squashed (pressure node). Wherever people move most, they're crowded least, and the reverse.

Tricky bits
  • Always ask "node of what?" The same point is a displacement node and a pressure antinode. If a question says "node" without saying which, it usually means displacement, as in the lecture's displacement profiles.
  • Closed end: displacement node, pressure antinode. Open end: displacement antinode, pressure node. Memorise this one line and you can draw every pipe.
  • Molecules don't flow through the pipe. Each one only wiggles about its own resting spot. The standing wave pattern sets how big each wiggle is.

05Case 1 · Pipe closed at both ends

Both ends are displacement nodes, exactly like a string clamped at both ends. So the same fitting rule applies: a whole number of half-wavelengths.

1st: λ1 = 2L    2nd: λ2 = L    3rd: λ3 = 2L3 λn = 2Ln,   fn = nv2L,   n = 1, 2, 3, … f1 = v2L fundamental
Practice example (my numbers): L = 0.50 m, v = 343 m/s
fundamental: f1 = v2L = 3432(0.50) = 343 Hz
2nd harmonic: λ2 = L = 0.50 m,   f2 = 2(343)2(0.50) = 686 Hz
3rd harmonic: λ3 = 2(0.50)3 = 0.333 m,   f3 = 1029 Hz

Analogy · a guitar string made of air

Walls at both ends do for air what clamps do for a string: they pin the motion to zero. So the closed-closed pipe has the same harmonic ladder as a guitar string: f1, 2f1, 3f1, and so on.

Tricky bits
  • Same formulas as the string, different physics. On the string, v depends on tension. In the pipe, v is the speed of sound in air.
  • Count from the diagram. The 3rd harmonic has 4 displacement nodes (2 at the walls, 2 inside) and 3 antinodes.
  • Solving backwards. Given f1, the length is L = v2f1. Don't forget the 2.

06Case 2 · Pipe closed at one end

Now the ends disagree. The closed end must be a displacement node, the open end must be a displacement antinode. The distance from a node to the nearest antinode is a quarter-wavelength, so the pipe must hold an odd number of quarter-wavelengths.

Lecture labelFitWavelengthFrequency
1st harmonicL = λ4λ1 = 4Lf1 = v4L
"2nd harmonic"L = 3λ4λ3 = 4L33f1
"3rd harmonic"L = 5λ4λ5 = 4L55f1
λn = 4Ln,   fn = nv4L,   n = 1, 3, 5, … odd n only f1 = v4L fundamental, half that of an open-open pipe of the same length

Pressure follows the swap rule from §4: at the closed end the pressure is maximum, at the open end it's zero.

Practice example (my numbers): L = 0.50 m, v = 343 m/s
fundamental: λ1 = 4L = 2.0 m,   f1 = v4L = 3434(0.50) = 171.5 Hz
next mode (n = 3): λ3 = 4(0.50)3 = 0.667 m,   f3 = 3 × 171.5 = 514.5 Hz
after that (n = 5): λ5 = 2.05 = 0.40 m,   f5 = 5 × 171.5 = 857.5 Hz
note: 2f1 = 343 Hz is not a resonance of this pipe

Analogy · blowing across a bottle

A bottle is a pipe closed at the bottom. Its note is low for its size because the pipe only holds a quarter of a wavelength in its fundamental. Pour in water (shorter L) and the note rises.

Tricky bits
  • Only odd n. Page 12 writes "n = 1, 2, 3, …" under the formula, but its own diagrams use λ1, λ3, λ5. Even n would put a node (or antinode) at both ends, which this pipe can't have. Use n = 1, 3, 5, … in the formula.
  • Two naming systems. The lecture calls the mode with λ3 = 4L3 the "2nd harmonic" (the 2nd allowed mode). Many textbooks call it the 3rd harmonic, because its frequency is 3f1. Either way, the frequency is 3f1. Read questions carefully and work from the wavelength or the n in the subscript.
  • Spotting the pipe from data. Resonances at 150, 250, 350 Hz are odd multiples of 50 Hz: a closed-one-end pipe with f1 = 50 Hz. The gap (100 Hz) is 2f1, not f1.

07Case 3 · Pipe open at both ends

Both ends are displacement antinodes (and pressure nodes). Antinode to antinode is a half-wavelength, so we're back to whole numbers of half-wavelengths, the same ladder as the closed-closed pipe and the string.

1st: λ = 2L    2nd: λ = L    3rd: λ = 23L λ = 2Ln,   fn = nv2L,   n = 1, 2, 3, … f1 = v2L fundamental

In the 1st harmonic, displacement is maximum at both ends and zero in the middle. Pressure is zero at both ends and maximum in the middle. It's the closed-closed picture with displacement and pressure swapped.

Practice example (my numbers): L = 0.50 m, v = 343 m/s
fundamental: f1 = 3432(0.50) = 343 Hz
2nd harmonic: λ = L = 0.50 m,   f2 = 686 Hz   (2 displacement nodes inside)
3rd harmonic: λ = 23(0.50) = 0.333 m,   f3 = 3 × 343 = 1029 Hz

Analogy · a flute

A flute is open at both ends (the mouth hole and the far end). Both ends breathe freely, so they're displacement antinodes. Overblowing jumps you up to 2f1, an octave higher. A closed-one-end pipe can't do that; its next note is 3f1.

Tricky bits
  • Open-open and closed-closed share the same frequencies for the same L and v. What differs is where the nodes sit: open-open has antinodes at the ends, closed-closed has nodes there.
  • Nodes inside, not at the ends. In the open-open nth harmonic there are n displacement nodes, all inside the pipe, and n + 1 antinodes (including both ends).
  • Quick sanity check: the closed-one-end fundamental v4L is half the open-open fundamental v2L for the same pipe length.

Part 4 · Interference of sound waves

08Adding two sound waves travelling the same way

Two sources S1 and S2 send sound waves with the same amplitude along the x-axis toward a point P. They're identical except for a phase constant:

s1 = sm cos(kx − ωt + φ1)    s2 = sm cos(kx − ωt + φ2) sR = [2sm cos(Δφ2)] cos(kx − ωt + φ1 + φ22) Δφ = φ1 − φ2 phase difference

The bracket 2sm cos(Δφ2) is the amplitude of the resultant at P. Unlike the standing wave, the second factor still has (kx − ωt): the result is a travelling wave, just louder or quieter than each source alone.

ConditionΔφAmplitudeName
Δφ2 = mπ2mπ (0, 2π, 4π, …)2sm (max)constructive
Δφ2 = (m + 12)π(2m + 1)π (π, 3π, 5π, …)0destructive

with m = 0, 1, 2, … Anything in between gives an amplitude between 0 and 2sm.

Lecture derivation: the resultant sound wave (page 2)
1. Identity: cos A + cos B = 2 cos(A + B2) cos(A − B2)
2. Let A = kx − ωt + φ1,   B = kx − ωt + φ2
3. Half sum: A + B2 = kx − ωt + φ1 + φ22
4. Half difference: A − B2 = φ1 − φ22 = Δφ2
5. So sR = s1 + s2 = [2sm cos(Δφ2)] cos(kx − ωt + φ1 + φ22)
6. Max when |cos(Δφ2)| = 1 ⟹ Δφ = 2mπ; zero when cos(Δφ2) = 0 ⟹ Δφ = (2m + 1)π
Try it: phase difference dial
s1s2sR = s1 + s2
Analogy · pushing a swing

Two people push a swing with equal force. Push together (in phase) and the swing goes twice as high. One pushes while the other pulls (half a cycle out of phase) and the swing goes nowhere. Anything in between gives something in between.

Tricky bits
  • Halve first. The amplitude uses cos(Δφ2), not cos(Δφ). For Δφ = 2π3 the amplitude is 2sm cos(π3) = sm, not 2sm cos(2π3).
  • Destructive needs an odd multiple of π. Δφ = 2π, 4π are constructive. Δφ = π, 3π, 5π are destructive.
  • Standing vs travelling. §2 added waves going opposite ways (standing wave). Here both go the same way, so the sum still travels.
  • Amplitude is a size. If cos(Δφ2) comes out negative, the size is the absolute value. The sign just shifts the phase.

09Path length difference (alternative analysis)

Where does Δφ come from in practice? If both sources emit in step, the phase difference at P comes only from the extra distance one wave travels. Wave 1 travels L1, wave 2 travels L2, and every extra wavelength of path adds 2π of phase:

ΔL = L1 − L2 [phase difference] = 2πλ [path length difference]   i.e.   Δφ = ΔLλ 2π constructive: ΔL = mλ    destructive: ΔL = (m + 12)λ,   m = 0, 1, 2, …

So the whole question reduces to one number: ΔLλ. A whole number means loud at P. A whole number plus a half means silence at P.

Lecture derivation: path difference to phase difference (pages 3 and 4)
1. Constructive (page 3): S2 sits one wavelength ahead of S1, so ΔL = λ. Crests line up at P. In general ΔL = mλ
2. Destructive (page 4): ΔL = λ2 puts a crest of one wave on a trough of the other. In general ΔL = (m + 12)λ
3. Convert to phase: one λ of path is 2π of phase ⟹ Δφ = ΔLλ2π
4. Check with constructive: ΔL = mλ ⟹ Δφ = mλλ2π = m2π ✓ (matches §8)
5. Check with destructive: ΔL = (m + 12)λ ⟹ Δφ = (2m + 1)π ✓
Practice example (my numbers): v = 340 m/s, f = 850 Hz, ΔL = 1.0 m
wavelength: λ = vf = 340850 = 0.40 m
ratio: ΔLλ = 1.00.40 = 2.5 = 2 + 12 ⟹ destructive (m = 2)
phase: Δφ = 2.5 × 2π = 5π   (odd multiple of π ✓)

Analogy · two runners on a track

Two runners with identical strides start from different spots and finish at the same line. If the head start is a whole number of strides, they land in step at the finish. If it's a whole number plus half a stride, one is mid-air while the other lands: perfectly out of step.

Tricky bits
  • Get λ first. Questions often give v and f. Compute λ = vf before comparing ΔL with λ.
  • Smallest destructive path difference is λ2 (m = 0), not λ. Smallest constructive one is 0.
  • Moving one speaker. Going from loud to the first silence takes an extra λ2 of path. Loud to the next loud takes a full λ.
  • This assumes the sources start in phase. If they don't, add their own phase difference on top of 2πλΔL.
