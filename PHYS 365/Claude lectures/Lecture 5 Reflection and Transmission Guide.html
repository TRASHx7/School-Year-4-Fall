PHYS 365 · Lecture 5 · Study guide

Reflection and transmission: a wave meets a new string

When a wave on one string reaches a different string, it splits. Part of it bounces back, part of it carries on. This lecture works out exactly how much of each, using two rules at the joint and one number for each string: its impedance Z.

About the numbers. The lecture works only in symbols, so the demos and quizzes use one running example of my own: τ = 100 N, μ1 = 0.01 kg/m, μ2 = 0.04 kg/m, f = 50 Hz, ym,i = 6 mm. That gives Z1 = 1 kg/s and Z2 = 2 kg/s. The lecture's own worked cases are the ring on a rod and the wall, and every demo has presets that reproduce them.

Part 1 · The setup

01 · p.1Two strings, three waves

Region I (x < 0) is a string with mass per length μ1 and tension τ1. Region II (x > 0) is a different string with μ2, τ2. They're tied together at x = 0. A wave comes in from the left. At the joint it splits, so there are three waves to keep track of:

Incident (moves +x, region I):  yi = ym,i sin(k1x − ωt) Reflected (moves −x, region I):  yr = ym,r sin(k1x + ωt) Transmitted (moves +x, region II):  yt = ym,t sin(k2x − ωt)

The goal of the whole lecture: find ym,r and ym,t in terms of ym,i. On the left string you see the sum yi + yr; on the right string you see only yt.

Notice what is shared and what isn't. All three waves have the same ω. The wave number changes with the string, because k = ω/v and each string has its own speed v = √(τ/μ).

Analogy · a shop window at dusk

Look at a shop window in the evening. You see your own reflection, and people inside can still see you. The light splits at the glass: some bounces back, some goes through. The joint between two strings is the glass. The colour (frequency) of the light doesn't change, but how it travels on the other side does.

Tricky bits
  • The reflected wave uses k1, not k2. It travels back along string 1, so it has string 1's speed and wavelength.
  • The sign inside the sine sets the direction. sin(kx − ωt) moves toward +x; sin(kx + ωt) moves toward −x.
  • Frequency stays, wavelength changes. On a slower (heavier) string the same ω gives a bigger k and a shorter λ. In the demo, set μ2 = 4μ1 and the waves on the right are half as long.

02 · pp.2 to 3Boundary conditions at the joint

Two rules hold at x = 0 at every instant. They're all you need to find the two unknown amplitudes.

1. Continuity (the string doesn't break):  yi + yr = yt  at x = 0 2. Slope (no kink at the joint):  ∂yi∂x + ∂yr∂x = ∂yt∂x  at x = 0

Rule 1 is obvious: the point at x = 0 has one height. Rule 2 is about force. The knot has no mass, so the vertical pulls on it from each side, τ ∂y/∂x, must cancel exactly (otherwise it would have infinite acceleration). With the same tension on both sides, that means the same slope.

Rule 1 alone already gives a clean amplitude equation:

ym,i = ym,r + ym,t "amplitude equivalence," p.3
Worked example (pp.2 to 3): continuity → amplitude equation
  1. Set x = 0 in each wave (the k x terms vanish):yi = (ym)i sin(−ωt),   yr = (ym)r sin(ωt),   yt = (ym)t sin(−ωt)
  2. Plug into yi + yr = yt:(ym)i sin(−ωt) + (ym)r sin(ωt) = (ym)t sin(−ωt)
  3. Use sin(−ωt) = −sin(ωt):−ym,i sin ωt + ym,r sin ωt = −ym,t sin ωt
  4. This holds at every t, so the coefficients of sin ωt must match:−ym,i + ym,r = −ym,t
  5. Rearrange:ym,i = ym,r + ym,t

Then (p.3): since yi + yr = yt at x = 0, the lecture also requires ∂yi/∂x + ∂yr/∂x = ∂yt/∂x there. That second rule is used in §4.

Zoomed in around the joint, frozen at one instant. Example strings: Z2/Z1 = 2, ym,i = 6 mm.
Analogy · a weightless referee

Picture the knot as a referee with zero mass standing between two tug-of-war teams who pull up and down. If the teams' vertical pulls didn't cancel exactly, a massless referee would shoot off instantly. So the pulls always balance, and that's the slope rule. The continuity rule is simpler: the referee can't be in two places at once.

Tricky bits
  • The minus signs come from sin(−ωt). Forget that sin(−ωt) = −sin(ωt) and you get ym,i + ym,r = ym,t, which is wrong for the way this lecture writes yr.
  • Other books get a different-looking equation. Many textbooks write the reflected wave so that continuity reads ym,i + ym,r = ym,t. Both are fine; they just define ym,r with opposite signs. Stick to one convention per problem. (This matters again in §5.)
  • Why the slope rule really holds. The lecture writes "since yi + yr = yt, then the derivatives are equal." Equal heights at one point don't force equal slopes on their own. The physical reason is the force balance on the massless knot.
  • You can cancel sin ωt only because the rule holds for all t. That's also why every wave must share the same ω.

Part 2 · Impedance

03 · p.4Impedance: how hard a string is to shake

Impedance measures how much vertical force it takes to make a point on the string move up and down at a given speed:

Z = force on the string (Fy)velocity amplitude (vy) = τkω = τv = √(τμ) = μv

A heavy or tight string has a big Z: it's hard to shake. A light or slack string has a small Z. Z depends only on the string (τ and μ), not on the wave's amplitude or frequency. Units: N·s/m = kg/s.

Why it matters: when the lecture solves for the amplitudes in §4, the answer depends on the two strings only through Z1 and Z2.

Worked example (p.4): from Fy/vy to √(τμ)
  1. Take the wave:y = ym sin(kx − ωt)
  2. Vertical force (eq. ①):Fy = τ(∂y/∂x) = τk ym cos(kx − ωt)  → amplitude τk ym
  3. Vertical velocity (eq. ②):vy = ∂y/∂t = −ω ym cos(kx − ωt)  → amplitude ω ym
  4. Divide the amplitudes (ym and the cosine cancel):Z = τk/ω
  5. Since v = ω/k:Z = τ/v
  6. Since v = √(τ/μ):Z = τ/√(τ/μ) = √(τμ)

Loaded with string 1 of the running example. All four forms of Z should agree.
Analogy · Ohm's law for strings

In a circuit, resistance is voltage per unit current: how much push you need for a given flow. Impedance is the same idea for a string: force per unit transverse velocity. Shaking the end of a heavy rope is like pushing current through a big resistor. You need a lot of force to get a little motion.

Tricky bits
  • Z doesn't depend on frequency, even though τk/ω has k and ω in it. Their ratio k/ω = 1/v is fixed by the string.
  • It's a ratio of amplitudes. Fy and vy both swing as cos(kx − ωt), so the cosine (and the minus sign from ∂/∂t) drops out. Z is always positive.
  • Same tension, different μ: Z2/Z1 = √(μ2/μ1). Four times heavier means twice the impedance.
  • Units are kg/s, not kg/m. A quick check: μv = (kg/m)(m/s).

Part 3 · Amplitudes

04 · pp.5 to 6Solving for the amplitudes

Now use the slope rule. Differentiate each wave with respect to x and set x = 0. Every cosine becomes cos(ωt) and cancels, leaving:

k1ym,i + k1ym,r = k2ym,t

Next swap k for Z. From Z = τk/ω we get k = Zω/τ, so k1 = Z1ω/τ1 and k2 = Z2ω/τ2. The tensions on both sides of the knot are equal (see Tricky bits), so ω/τ cancels and the slope rule becomes Z1(ym,i + ym,r) = Z2ym,t. Two equations, two unknowns:

ym,r = Z2 − Z1Z1 + Z2 ym,i     ym,t = 2Z1Z1 + Z2 ym,i
Worked example (pp.5 to 6): slope rule → ym,r and ym,t
  1. Differentiate each wave (∂/∂x of sin(kx ± ωt) is +k cos(kx ± ωt)):k1ym,i cos(k1x − ωt) + k1ym,r cos(k1x + ωt) = k2ym,t cos(k2x − ωt)
  2. Set x = 0. cos(−ωt) = cos(ωt), so all three cosines are the same and cancel (eq. ③):k1ym,i + k1ym,r = k2ym,t
  3. Substitute k = Zω/τ (same ω and τ on both sides):Z1ym,i + Z1ym,r = Z2ym,t
  4. From §2, ym,t = ym,i − ym,r. Substitute:Z1ym,i + Z1ym,r = Z2ym,i − Z2ym,r
  5. Collect the ym,r terms:ym,r(Z1 + Z2) = (Z2 − Z1)ym,i  →  ym,r = [(Z2 − Z1)/(Z1 + Z2)] ym,i
  6. Back into ym,t = ym,i − ym,r:ym,t = [(Z1 + Z2) − (Z2 − Z1)]/(Z1 + Z2) · ym,i = [2Z1/(Z1 + Z2)] ym,i

Analogy · splitting a bill with two clues

Two friends split a bill and you want to know each share. One clue gives the total (continuity: ym,r + ym,t = ym,i). The other says how they split it (slope: a weighting by Z1 and Z2). Either clue alone leaves you guessing; together they pin down both shares.

Tricky bits
  • The tensions must be equal. The lecture writes τ1 and τ2, but the clean Z-only answer needs τ1 = τ2. That's true physically: the massless knot can't have an unbalanced horizontal pull either. So k1/k2 = Z1/Z2.
  • No sign flip here. Unlike the sines in §2, cos(−ωt) = cos(ωt), and ∂/∂x of sin(k1x + ωt) is +k1 cos(…). Every term in the slope rule comes out positive.
  • Substitute, don't guess. Most algebra slips happen in step 4. Replace ym,t with ym,i − ym,r before collecting terms.

05 · pp.7 to 8Reflection and transmission coefficients

Divide each amplitude by the incident one and you get two numbers that depend only on the impedances:

r = amplitude of reflected waveamplitude of incident wave = ym,rym,i = Z2 − Z1Z1 + Z2 t = amplitude of transmitted waveamplitude of incident wave = ym,tym,i = 2Z1Z1 + Z2

A handy check that falls out of continuity: t = 1 − r. And the big picture:

  • Z2 = Z1 (matched): r = 0, t = 1. No reflection at all.
  • Z2 > Z1 (into a harder-to-shake string): |r| grows toward 1, t shrinks toward 0.
  • Z2 < Z1 (into an easier string): t grows above 1, up to 2.

Reading the sign of r

This is the one part of the lecture where you have to be careful. Because the lecture writes the reflected wave as sin(k1x + ωt), at the joint it equals +ym,r sin ωt while the incident wave equals −ym,i sin ωt. That built-in minus sign means a positive r from the formula describes a reflection that moves opposite to the incident wave at the joint: an inverted pulse. The special-case pages (§6, §7) instead report r with the "what you see" sign. Here is how they line up:

Caser from the p.7 formulaReflected pulse you seeHow the lecture reports it
Z2 > Z1 (heavier, or a wall)positive (wall: → +1)invertedwall, p.11: r ≅ −1, ym,r = −ym,i
Z2 < Z1 (lighter, or a ring)negative (ring: → −1)uprightring, p.10: r = 1, ym,r = ym,i
Z2 = Z10noneno reflection

Rule that never fails: going into a higher Z flips the pulse; going into a lower Z doesn't. Get the size from |r| = |Z2 − Z1|/(Z1 + Z2) and the orientation from that rule. In this guide's quizzes, "r from the lecture's formula" always means the signed p.7 value.

r = (Z2 − Z1)/(Z1 + Z2) t = 2Z1/(Z1 + Z2)
Analogy · billiard balls

Roll a ball into another one at rest. Equal masses (Z2 = Z1): the first ball stops dead and the second takes all the motion. No "reflection." Into a bowling ball (Z2 ≫ Z1): your ball bounces back, reversed, and the bowling ball barely moves. That's the wall. Into a ping-pong ball (Z2 ≪ Z1): your ball keeps going forward and the ping-pong ball flies off faster than your ball was moving. That's t > 1.

Tricky bits
  • The sign of r depends on convention. See the table above. If you plug Z2 = ∞ straight into the p.7 formula you get +1, but the lecture writes −1 for the wall. Both describe the same inverted pulse.
  • t can be bigger than 1. That's not free energy: power also depends on Z (§9).
  • t is never negative. Impedances are positive, so 2Z1/(Z1 + Z2) > 0. The transmitted pulse is always upright.
  • |r| ≤ 1 and 0 ≤ t ≤ 2 always. If you get anything outside those ranges, you've swapped Z1 and Z2 or dropped a factor of 2.

06 · pp.9 to 10Special case: ring on a rod (Z2 = 0)

Tie the end of string 1 to a massless ring that slides freely up and down a vertical rod. Nothing beyond the joint resists vertical motion, so it takes zero force to move the end at any speed: Z2 = 0. This is a "free end."

Result: the pulse comes back upright and full size (ym,r = ym,i), and nothing is transmitted. While the pulse is reflecting, the ring rises to twice the incident height, because the incident and reflected pulses add there.

Worked example (pp.9 to 10): the ring on a rod
  1. Start from the coefficient:r = (Z2 − Z1)/(Z1 + Z2)
  2. "Allow for rod-ring motion (same amplitude sign)": the lecture puts a minus sign in front, then sets Z2 = 0:r = −(Z2 − Z1)/(Z1 + Z2) = −(0 − Z1)/(Z1 + 0) = Z1/Z1 = 1
  3. So:∴ ym,r = ym,i
  4. There is no string past the ring, so ym,t = 0:t = (ym,t = 0)/ym,i = 0  (no transmitted wave)

Why the minus sign: it converts the p.7 convention (where an upright reflection comes out negative) into the "what you see" sign. See the table in §5.

Analogy · cracking a whip

The free tip of a whip moves much farther and faster than the handle. A free end has nothing holding it back, so when the pulse arrives the end overshoots: it rises to twice the pulse height, then sends the pulse back the same way up.

Tricky bits
  • Plugging Z2 = 0 straight into the p.7 formula gives r = −1. The lecture's extra minus sign turns that into r = 1. Both mean the same upright reflection; the lecture's answer to remember is r = 1, ym,r = ym,i.
  • The t formula gives 2, but the lecture says t = 0. 2Z1/(Z1 + 0) = 2 is how far the ring itself moves (2 × ym,i). It isn't a wave, since there's no string to carry one. Power agrees: T = (Z2/Z1)t² = 0 × 4 = 0.
  • "Same amplitude sign" on p.10 means the reflected pulse is the same way up as the incident one.

07 · p.11Special case: string tied to a wall (Z2 = ∞)

Now tie the end to a wall. The wall won't move no matter how hard you pull, so it would take infinite force to give it any speed: Z2 = ∞. This is a "fixed end."

Result: the pulse comes back inverted and full size (ym,r = −ym,i), and nothing goes through the wall. The tied point never moves, because the incident and inverted reflected pulses cancel there at every instant.

Worked example (p.11): the wall
  1. Reflection coefficient with Z2 = ∞:r = (Z2 − Z1)/(Z2 + Z1) = (∞ − Z1)/(∞ + Z1)
  2. The lecture's result:r ≅ −1  →  ym,r = −ym,i
  3. Transmission coefficient:t = 2Z1/(Z1 + Z2) = 2Z1/∞  →  t ≈ 0
  4. No transmitted wave through the wall.

As with the ring, the lecture reports the "what you see" sign. The ratio (∞ − Z1)/(∞ + Z1) by itself tends to +1 in the p.7 convention, which is that same inverted pulse (table in §5).

Analogy · a rope tied to a doorknob

Flick a rope tied to a doorknob and the bump comes back upside down. The knob can't move, so when your upward bump arrives, the knob pulls the rope down to keep its own end still. That downward pull launches the upside-down return pulse.

Tricky bits
  • Ring and wall are mirror images. Free end: upright, end moves 2×. Fixed end: inverted, end doesn't move. Both: |r| = 1, no transmitted wave.
  • "≅" and "≈" are deliberate. ∞ is a limit. A real "wall" is just a string with Z2 ≫ Z1, so |r| is a hair under 1 and t a hair above 0.
  • Don't mix the signs. For the wall the lecture says r ≅ −1. If you plug ∞ into (Z2 − Z1)/(Z2 + Z1) mechanically you get +1. The picture (inverted) is what matters.

Part 4 · Power

08 · p.12Power on a string, and the reflected fraction R

The average power a sinusoidal wave carries along a string can be written neatly with Z:

Pave = ½ μv ym² ω² = ½ Z ym² ω²

The power reflection coefficient R is the fraction of the incident power that comes back. Both waves are on string 1, so Z1 and ω cancel and you're left with the amplitude ratio squared:

R = PrPi = r²
Worked example (p.12): Z = μv and R = r²
  1. Why μv = Z:v = √(τ/μ) → τ = μv²,   so   Z = √(μτ) = √(μ²v²) → Z = μv
  2. So the average power is:Pave = ½ μv ym² ω² = ½ Z ym² ω²
  3. Ratio of reflected to incident power (both on string 1):R = Pr/Pi = (½ Z1ym,r² ω²)/(½ Z1ym,i² ω²)
  4. Everything but the amplitudes cancels:R = ym,r²/ym,i² = r²

Analogy · kinetic energy, ½mv²

Each bit of string moves up and down with top speed ymω. Power is ½ Z × (ymω)², which looks just like ½ × mass × speed². Z plays the role of mass: a heavier string carries more energy at the same wiggle.

Tricky bits
  • Use ω, not f. ω = 2πf. Using f undercounts the power by (2π)² ≈ 39.5.
  • Convert mm to m before squaring. 6 mm is 0.006 m, and ym² = 3.6 × 10⁻⁵ m².
  • R = r² ignores the sign of r, so the convention mess in §5 doesn't matter here.
  • Power goes as ym² and ω². Double either one and the power goes up 4×.

09 · p.13Transmitted power and T

The transmitted wave travels on string 2, so its power uses Z2, while the incident power uses Z1. That leaves a factor Z2/Z1 in front:

T = PtPi = Z2Z1 t²

A good check (not written in the lecture, but it follows from its formulas): R + T = 1. Every bit of incident power is either reflected or transmitted; nothing is lost at the knot. For the ring and the wall, R = 1 and T = 0.

Worked example (p.13): T = (Z2/Z1)t², plus the R + T check
  1. Transmitted power over incident power:T = Pt/Pi = (½ Z2ym,t² ω²)/(½ Z1ym,i² ω²)
  2. Cancel ½ and ω²:T = (Z2/Z1)[ym,t/ym,i]²
  3. That bracket is t:T = (Z2/Z1)t²
  4. Check (extra): R + T = [(Z2 − Z1)² + (Z2/Z1)(2Z1)²]/(Z1 + Z2)²= [Z2² − 2Z1Z2 + Z1² + 4Z1Z2]/(Z1 + Z2)² = (Z1 + Z2)²/(Z1 + Z2)² = 1

Analogy · an exchange rate

Think of amplitude as money in two different currencies. On string 2, each millimetre of amplitude is "worth" Z2/Z1 times as much power as on string 1. So t² alone is like counting foreign cash without converting it. The factor Z2/Z1 is the exchange rate. The ping-pong ball from §5 moves fast (big t) but carries little energy, because it's light.

Tricky bits
  • Typo on p.13. The first fraction shows Z2 in the denominator too. It should be Z1, since the incident wave is on string 1. The next step (Z2/Z1)[ym,t/ym,i]² and the final answer are correct.
  • T ≠ t². The most common exam slip. In the running example t² = 0.444 but T = 0.889.
  • T ≤ 1 even when t > 1. When t is big, Z2 is small, and the factor brings T back down.
  • Use R + T = 1 to check your work. If they don't add to 1, something's off.
